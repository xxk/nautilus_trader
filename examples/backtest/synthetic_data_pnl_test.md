# synthetic_data_pnl_test.py 解读

## 定位

这是一个最小化 PnL 验证示例，文件内自带 `MinimalStrategy`，用于检查在合成数据场景下损益计算是否符合预期。

## 主流程

1. 手工生成测试数据和测试合约。
2. 创建回测引擎与账户环境。
3. 运行文件内置的极简策略。
4. 用结果验证损益、头寸和事件流是否正确。

## 关键点

- 这类脚本更接近“验证夹具”而不是正式策略样例。
- 真正价值在于帮助理解引擎如何记账和结算。
- 当你怀疑 PnL 口径时，这类最小例子非常有用。

## 学习价值

适合用来理解 Nautilus 回测账务链路，而不是学习交易信号本身。
