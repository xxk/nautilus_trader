# bybit_request_custom_endpoint.py 解读

## 定位

这是一个高级示例，演示如何在 Bybit live 节点里通过策略访问自定义 API 端点。

## 主流程

1. 配置 Bybit 节点和连接参数。
2. 运行 `RequestDemoStrategy`。
3. 在策略生命周期中调用自定义接口请求。
4. 结合 Nautilus 的事件驱动日志观察结果。

## 关键点

- 重点不在交易信号，而在扩展 adapter 能力。
- 当官方标准接口不够用时，这个示例展示了扩展方向。
- 学习时应关注“如何在策略中安全地调用额外 API”。

## 学习价值

适合作为二次开发交易所适配器能力的入口样板。
