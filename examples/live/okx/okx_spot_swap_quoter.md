# okx_spot_swap_quoter.py 解读

## 定位

这是 OKX 上较复杂的 live 示例，文件内自带 `SpotSwapQuoter`，目标是围绕现货与永续之间做联动报价。

## 主流程

1. 配置 OKX data/exec client。
2. 在策略内部同时关注 spot 与 swap 合约。
3. 基于行情变化构造双边报价或联动下单意图。
4. 通过节点持续运行报价策略。

## 关键点

- 这不是简单的单标的趋势策略，而是更偏向联动做市/报价策略。
- 文件内自定义策略类较多，适合从“策略结构”角度仔细读。
- 如果要研究跨合约联动逻辑，这份示例比普通 EMA 示例更有价值。

## 学习价值

适合理解官方如何在 live 示例里写一个自定义复杂 Strategy 子类。
