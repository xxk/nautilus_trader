# binance_spot_demo_exec_tester.py 解读

## 定位

这是 Binance 现货 demo 环境的执行测试脚本，仍然以 `ExecTester` 为主。

## 主流程

1. 配置 demo 环境 client。
2. 选择测试标的并装配执行测试策略。
3. 启动节点进行订单链路验证。
4. 观察日志和订单状态回报。

## 关键点

- 这个脚本的主要价值是“再往前退一步”的低风险演练。
- 学习重点不在策略逻辑，而在环境切换和 adapter 行为。
- 和正式环境脚本相比，结构大体相同，差别主要在配置。

## 学习价值

适合先熟悉节点生命周期与 Binance 配置项，再进入真实环境。
