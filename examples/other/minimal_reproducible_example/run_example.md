# run_example.py 解读

## 定位

这是一个“最小可复现案例”的回测入口脚本，用来最小化复现场景和问题。

## 主流程

1. 手工生成合成 Bar 数据。
2. 创建 `BacktestEngine` 和测试合约。
3. 实例化同目录里的 `DemoStrategy`。
4. 运行回测并快速验证行为。

## 关键点

- 这个脚本的价值在于“最小”和“可控”，不是复杂策略。
- 数据、合约和策略都尽量收缩到最小规模，便于定位问题。
- 当你要给官方提 bug 或自测某个边界问题，这种例子很重要。

## 学习价值

适合理解如何构造一个最小、可复现、可回放的 Nautilus 案例。
