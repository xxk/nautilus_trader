## 🏗️ 核心设计理念

### 1. **事件驱动架构**
- 所有操作由事件驱动（Market Data、Order、Time Signal）
- 决定性时间模型（Deterministic Time Model）
- 研究和实盘使用相同的执行语义

### 2. **多语言融合**
```
Python (策略层) ◄──PyO3──► Rust (引擎层)
  ↓ 高易用性                ↓ 高性能
  策略编写、配置             数据处理、订单执行
  分析工具、调试             网络通信、持久化
```

### 3. **模式隔离**
```
模式1: 研究          模式2: 实盘
────────────        ──────────
历史数据 → 回测 → 分析   实时数据 → 执行 → 监控
设定时间    确定性      系统时间   实时性
```

### 4. **适配器模式**
- 任何交易所/数据源只需实现标准适配器接口
- 策略代码与具体实现解耦

## 🧩 核心模块详解

### A. 基础构件层 (Foundation)

#### `core` - 核心基础库 (905K行 Rust)
| 子模块 | 职责 | 关键类型 |
|--------|------|--------|
| **time** | 时间管理、原子时钟 | `UnixNanos`, `AtomicClock` |
| **uuid** | 身份识别、合约ID | `UUID4`, `usize` hash |
| **collections** | 高效数据结构 | `HashMap`, `FxHashMap` |
| **math** | 数学计算、插值 | `f64` 精度处理 |
| **serialization** | 序列化框架 | `Serialize`, `Deserialize` |

**用途**: 所有其他模块的基础依赖

---

#### `model` - 数据模型层 (80K行 Rust)
```
Currency
  ↓
Instrument (合约)
  ├─ Symbol (代码)
  ├─ Venue (交易所)
  ├─ Asset Class (资产类)
  └─ Price/Quantity (精度定义)
  
Order (订单)
  ├─ OrderId
  ├─ Symbol
  ├─ Side (BUY/SELL)
  ├─ OrderType (LIMIT/MARKET/...)
  └─ TimeInForce (IOC/FOK/GTC/...)

Position (持仓)
  ├─ Instrument
  ├─ Quantity
  ├─ AvgPrice
  └─ PnL

Bar/Tick (行情)
  ├─ Timestamp
  ├─ Open/High/Low/Close
  └─ Volume
```

### C. 连接层 (Connectivity)

#### `adapters` - 交易所适配器
```
标准适配器接口:
  
┌────────────────────────┐
│   AdapterInterface      │
├────────────────────────┤
│ + connect()            │
│ + disconnect()         │
│ + subscribe(Symbol)    │
│ + submit_order(Order)  │
│ + cancel_order(OrderId)│
└────────────────────────┘
         △
    ┌────┴────┬─────────┬──────────┬──────────┐
    │         │         │          │          │
  Binance   IB       Bybit     dYdX      Kraken
 (CEX)    (股票/期权)  (期货)   (DEX)     (CEX)
```

**关键实现** (Python + Rust):
- IB Adapter - Interactive Brokers 股票/期权/期货
- Binance Adapter - 加密货币交易
- Custom Adapters - 用户自定义

#### `live` - 实盘执行 (70K行 Rust)
```
实时流程:
  
市场数据 → 触发信号 → 生成订单 → 提交 → 监控
 (tick)     (Python)   (Python)   (Rust)  (Rust)
  
实时错误处理:
- 连接异常 → 重连
- 订单拒绝 → 重试/取消
- 流量限制 → 等待/排队
```

### D. 执行层 (Execution Layer)

#### `execution` - 订单执行引擎 (85K行 Rust)
```
订单生命周期管理:

Submitted
  ↓
Accepted ─→ PartiallyFilled ─→ Filled
  ↓                              ↓
Rejected                      Closed
  ↓
Canceled
```

**子模块**:
- `OrderManager` - 订单状态追踪
- `PositionManager` - 持仓计算
- `AccountManager` - 账户资金管理
- `ExecutionClient` - 执行接口

#### `trading` - 策略执行 (85K行 Rust)

策略执行链:

┌──────────────┐
│  Bar 事件    │

### E. 分析层 (Analytics)

#### `analysis` - 实时分析 (70K行 Rust)
| 模块 | 功能 |
|------|------|
| **indicators** | 技术指标计算 |
| **statistics** | 统计分析 |
| **portfolio** | 组合分析 |

#### `indicators` - 指标库 (120K行 Rust)
```
支持指标:
  移动平均    → SMA, EMA, DEMA, TEMA, WMA
  动量型      → RSI, MACD, Stochastic
  波动率      → ATR, Bollinger Bands, Standard Dev
  趋势型      → ADX, CCI, Ichimoku
  成交量      → OBV, CMF, VWAP
  自定义      → 用户编写或 Python 扩展
```

#### `portfolio` - 投资组合管理 (65K行 Rust)
```
组合指标:

组合价值 ◄── 账户余额 + 持仓市值
PnL    ◄── 已实现盈亏 + 未实现盈亏
杠杆率  ◄── (市值 / 自有资金)
最大亏损 ◄── 历史最高 - 当前
```

#### `risk` - 风控管理 (60K行 Rust)
```
风控规则执行:

订单请求
  ↓
├─ 账户余额检查 → 是否有足额资金?
├─ 头寸限制检查 → 是否超过最大持仓?
├─ 日内亏损检查 → 日亏是否超限?
├─ 风险限额检查 → 综合风险是否超限?
└─ 成交限制检查 → 成交价格是否合理?
  ↓ 全部通过
  ✅ 允许提交
```

```
┌─────────────────────────────────────────────────────────────────┐
│                        实盘交易完整流程                           │
└─────────────────────────────────────────────────────────────────┘

【第1步】市场数据获取
  ┌────────────────────┐
  │  交易所 WebSocket   │
  │  (Tick/OrderBook)   │
  └────────┬───────────┘
           │ 原始消息
           ↓
  ┌────────────────────┐
  │ Adapter 解析器      │
  │ • 数据转换          │
  │ • 验证完整性        │
  └────────┬───────────┘
           │ 标准化数据
           ↓
  ┌────────────────────┐
  │ 缓存管理器          │
  │ • 更新 Bar/Tick     │
  │ • 计算指标          │
  └────────┬───────────┘
           │ 事件发布
           ↓
  ⚡ 事件总线 (Event Bus)


【第2步】策略决策
  ┌────────────────────┐
  │ Python 策略回调     │
  │ on_bar() / on_tick()│
  └────────┬───────────┘
           │ 计算信号
           ↓
  ┌────────────────────┐
  │ 生成订单对象        │
  │ • Symbol            │
  │ • Side (BUY/SELL)  │
  │ • Quantity          │
  │ • Price (LIMIT/MKT) │
  └────────┬───────────┘
           │ 提交订单
           ↓
  ⚡ 事件总线


【第3步】风险控制
  ┌────────────────────┐
  │ 风控检查器          │
  │ • 余额充足?         │
  │ • 头寸限制?         │
  │ • 日亏限制?         │
  │ • 成交价合理?       │
  └────────┬───────────┘
           │ 都通过?
        ┌──┴──┐
        │是   │否
        ↓     ↓
       ✅   ❌ 拒绝
                │
         ┌──────┴──────┐
         │ 生成拒绝事件  │
         └──────┬───────┘
                │
          回调 Python
          (on_order_rejected)


【第4步】订单提交与追踪
  ┌────────────────────┐
  │ OrderManager       │
  │ • 生成 OrderId     │
  │ • 记录初始状态     │
  │ • Submitted → 队列 │
  └────────┬───────────┘
           │ 异步提交
           ↓
  ┌────────────────────┐
  │ Adapter 发送        │
  │ 通过 REST/WebSocket │
  │ 到交易所            │
  └────────┬───────────┘
           │ API 响应
           ↓
  ┌────────────────────┐
  │ 订单状态更新        │
  │ Submitted→Accepted │
  └────────┬───────────┘
           │ 事件发布
           ↓
  ⚡ 事件总线
    ├─ on_order_accepted
    └─ Python 策略收到回调


【第5步】成交处理
  ┌────────────────────┐
  │ 交易所成交消息      │
  │ (Trade/Fill)        │
  └────────┬───────────┘
           │ Adapter 解析
           ↓
  ┌────────────────────┐
  │ ExecutionManager    │
  │ • 状态: PartialFill │
  │ • 累计数量 += filled│
  │ • 计算成交价均值    │
  └────────┬───────────┘
           │ 更新持仓
           ↓
  ┌────────────────────┐
  │ PositionManager     │
  │ Qty += filled_qty   │
  │ AvgPrice 重新计算   │
  │ PnL 根据入场价计算  │
  └────────┬───────────┘
           │ 事件发布
           ↓
  ⚡ 事件总线
    └─ on_trade()  (Python 收到)


【第6步】实时分析 (并行)
           成交事件 ┐
                  ├──→ 【实时PnL计算】
      收盘价 更新 ┘        ├─ 实现盈亏
                          ├─ 浮动盈亏
                          └─ 回撤计算
                
          一分钟一次 ┐
                  ├──→ 【组合指标更新】
          账户更新 ┘        ├─ 组合价值
                          ├─ 风险边际
                          └─ 杠杆率


【第7步】监控与告警 (异步)
  ┌────────────────────┐
  │ 日志/监控系统       │
  │                    │
  │ • 所有关键事件记录  │
  │ • 性能指标收集      │
  │ • 异常告警判断      │
  │ • 持久化存储        │
  └────────────────────┘
```

  ├─ instrument: Instrument

  ├─ client_trade_id: "TRADE-001"
  ├─ instrument: Instrument
  ├─ filled_quantity: 50
  ├─ filled_price: 150.25
  └─ timestamp: <ts>

Account (账户)
  ├─ cash_balance: 50000.00  (可用资金)
  ├─ equity: 107500.00       (总权益)
  ├─ positions: Vec<Position>
  └─ orders: Vec<Order>
